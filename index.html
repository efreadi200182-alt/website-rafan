Tools & Materials

Alat & Bahan

Beberapa perangkat dan bahan yang diperlukan untuk membuat kabel LAN dengan konektor RJ45.

🔌

Kabel UTP

Media transmisi jaringan yang terdiri dari pasangan kabel twisted pair.

🔗

RJ45

Konektor yang digunakan untuk menghubungkan kabel UTP ke perangkat jaringan.

🛠️

Tang Crimping

Digunakan untuk memasang dan mengunci kabel UTP pada konektor RJ45.

🧪

LAN Tester

Alat untuk menguji apakah susunan kabel LAN sudah terhubung dengan benar.

✂️

Stripper

Digunakan untuk membuka lapisan luar kabel UTP sebelum proses penyusunan.

Cable Assembly

Perakitan Kabel LAN Crossover

Ikuti setiap langkah secara berurutan agar kabel LAN dapat digunakan untuk koneksi langsung antar dua laptop.

Susunan Kabel RJ45

Untuk kabel crossover, susunan kedua ujung kabel dibuat berbeda.

1
Putih / Oranye
2
Oranye
3
Putih / Hijau
4
Biru
5
Putih / Biru
6
Hijau
7
Putih / Coklat
8
Coklat

Ujung A menggunakan T568B dan ujung B menggunakan T568A untuk konfigurasi crossover.



01

Siapkan Kabel UTP

Siapkan kabel UTP sesuai panjang yang diperlukan. Gunakan stripper untuk membuka bagian luar kabel.

02

Susun Kabel

Pisahkan pasangan kabel kemudian susun warna kabel sesuai standar T568B dan T568A.

03

Potong Ujung Kabel

Rapikan dan ratakan ujung kabel menggunakan bagian pemotong pada tang crimping.

04

Masukkan ke RJ45

Masukkan seluruh kabel ke konektor RJ45 dan pastikan urutan warnanya tidak berubah.

05

Crimping

Masukkan RJ45 ke tang crimping kemudian tekan dengan kuat hingga konektor terkunci.

06

Uji LAN Tester

Hubungkan kedua ujung kabel ke LAN Tester. Pastikan indikator pin berjalan sesuai urutan.

Peer To Peer

Hubungkan 2 Laptop

Setelah kabel crossover selesai dibuat dan diuji, kabel dapat digunakan untuk koneksi langsung antar dua laptop.

💻 Laptop 1

Sambungkan kabel LAN ke port Ethernet. Kemudian buka pengaturan IPv4.

IP Address 10.10.10.1
Subnet Mask 255.0.0.0

💻 Laptop 2

Sambungkan ujung kabel lainnya ke laptop kedua, kemudian masukkan konfigurasi IPv4.

IP Address 10.10.10.2
Subnet Mask 255.0.0.0

01

Buka Network Settings

  • Control Panel
  • Network and Internet
  • Network and Sharing Center
  • Change adapter settings
02

Atur IPv4

Klik Ethernet → Properties → Internet Protocol Version 4 (TCP/IPv4). Masukkan alamat IP sesuai laptop masing-masing.

03

Aktifkan Network Discovery

Buka Advanced Sharing Settings. Aktifkan Network Discovery dan File Sharing.

04

Nonaktifkan Password Protected Sharing

Untuk kebutuhan praktikum, opsi password protected sharing dapat dinonaktifkan agar proses sharing lebih mudah.

Network Test

Uji Koneksi dengan Ping

Gunakan Command Prompt untuk memastikan kedua laptop dapat saling berkomunikasi melalui jaringan LAN.

C:\Users\User> ping 10.10.10.2

Jika muncul balasan seperti Reply from..., koneksi jaringan berhasil.

File Sharing

Sharing File Antar Laptop

Bagikan dokumen dari laptop pertama ke laptop kedua menggunakan fitur Network Sharing pada Windows.

01

Pilih Folder

Buat atau pilih folder yang berisi dokumen yang ingin dibagikan.

02

Properties

Klik kanan folder → Properties → Sharing → Advanced Sharing.

03

Aktifkan Sharing

Centang Share this folder lalu atur permission sesuai kebutuhan praktikum.

04

Akses dari Laptop 2

Pada File Explorer laptop kedua, masukkan alamat jaringan seperti:

\\10.10.10.1
